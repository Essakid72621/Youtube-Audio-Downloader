# Youtube-Audio-Downloader
This program will allow you to download playlists, or singular mp3 audios from YouTube, its fully open sourced, free to use, and runs entirely on your pc (Other from well, installing the mp3's).

# Additional info
It keeps metadata (For example author names) & It's quick!
You can even select a custom output path.

# Project time
This python project took me around a day to make, and I made it for myself so that I don't have to use those websites like Y2Mate.
It's a lot faster then those websites too, since it downloads the mp3's imedientely!
It wasn't too hard to make, I used kivy for the GUI and yt_dlp for downloading youtube mp3's
